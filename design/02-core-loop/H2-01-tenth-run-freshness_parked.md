# H2-01 · Tenth-run freshness

- **IF/THEN:** IF a player has cleared The Dark Fortress on Normal ten times, THEN in their next session they still choose to start a run (a different party, a set piece still missing, or a higher difficulty) rather than leave the hall within two minutes.
- **Source section:** §3 Core Loop — "why repetition 10 differs from repetition 1"
- **Cheapest killing test:** desktop Explorer, live LAND; watch three returning players who have 10+ clears (the hero save records clears per level and difficulty) and note whether they start a run and which of the three reasons applies, 30 min
- **Key metric:** returning 10+-clear players who start at least one run in the session; failure is fewer than 2 of 3
- **Mobile-sensitive:** no
- **Tested on:** —
- **Parked:** 2026-09-22
